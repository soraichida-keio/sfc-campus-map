主な機能

3D マップ

建物をクリックすると、階ごとに分解して教室を表示。真上からの表示にも切り替えられます。

教室を探す

66教室の定員・大きさ・机・4K・アクティブラーニングで絞り込み。教室番号(κ21 など)から場所が分かります。

経路・徒歩時間

バス停・門・建物・教室から、歩く道を3Dの地図に線で表示。「ふつう」と「急ぎ足」の目安時間つき。

時間割プランナー

授業と教室を入れると、休み時間に間に合うかを判定。2D の地図に動線も描きます。データは端末の中だけ。

新入生ガイド

最初にやること、チェックリスト、授業の時間、SFC のことば。公式資料にもとづき出典つき。

施設・アクセス・FAQ

学食や窓口の場所、湘南台・辻堂からのバス、よくある質問24問。

案内キャラ「ねる」

右下のねるに質問すると、声と吹き出しで答え、地図も動かします。口パクつき。

スマホ対応

スマホでは下のタブで操作でき、マップとねるが前面に出ます。ホーム画面に追加もできます。

ねるの使い方(右下の「何でも聞いてね！」をタップ)
  1. 右下のねるをタップすると、質問の画面が開きます(声が出ます。音量とマナーモードを確認)。
  2. 下の入力欄か、例のボタンで質問します。
  3. 声と吹き出しで答え、マップ画面では地図が動き、ほかのページでは小さな地図で場所を見せます。

使っているデータ

  • 建物の形・配置: 慶應義塾の公式キャンパスマップ(バリアフリーマップ)をもとに作図
  • 教室の定員・設備: SFC Classroom(公式)の66教室
  • 授業の時間・窓口・手続き: SFC GUIDE 2026 などの公式資料(出典つき)
  • 歩く距離: OpenStreetMap の建物と突き合わせて縮尺を確認(平均誤差 2.5m)

プライバシーと費用

  • アカウント登録・アクセス解析・広告はなし
  • 時間割やチェックリストは、端末のブラウザの中にだけ保存
  • ねるへの質問は外部に送らない(AI ではなく、サイト内のデータから答える仕組み)
  • 声は、事前に録音した合成音声(AivisSpeech「まお」)を配信
  • Cloudflare の無料枠で運用。サーバーの費用はかかりません
正確さについて(必ずお読みください)
このサイトは学生による非公式のサイトで、慶應義塾とは関係がありません。教室の「階」は教室番号の十の位からの推定、建物の高さは目安、歩く時間は階段・坂・混雑を含まない目安です。時限・窓口・推奨スペックは2026年度の資料時点なので、最新情報は必ず公式サイトで確認してください。

今後の予定(候補)

  • GPS の現在地を地図に表示し、現在地から教室まで案内(曲がる指示・ルート外れの再計算)
  • 階段を避けるバリアフリー経路
  • シラバスの教室を貼り付けて時間割に取り込む
  • 英語版・やさしい日本語版、答えの誤りの報告ボタン

しくみ(要点)

  • Cloudflare Workers の静的サイト。3D は Three.js、経路は地図画像から作った格子で最短経路を計算
  • PWA 対応(ホーム画面に追加できます)
  • ソースコードは非公開の GitHub リポジトリで管理
