# 地図データの作り方(再現手順)

元データ: 慶應義塾の公式バリアフリーマップ PDF(2023年2月版) https://www.sfc.keio.ac.jp/en/docs/sfcmap_en.pdf
作業は一時フォルダで行い、結果だけを `src/geom.json` `src/rooms.json` `public/ground.png` に置く。

1. 教室(66室): `01_scrape_rooms.py` → `02_parse_rooms.py`(classroom.sfc.keio.ac.jp の個別ページを 0.4 秒間隔で取得)→ 整形して `src/rooms.json`
2. PDF を 300dpi で描画: `pdftoppm -r 300 -f 1 -l 1 -png sfcmap_en.pdf hi`
3. 色で分類(建物=オレンジ 250,190,70 / 芝 150,205,161 / 池 90,200,255 / 敷地外 125,129,140 / 運動場 255,248,176 / 道 219,220,220 / 広場 白): `10_classify_ground.py`
4. 掃除: `11`(吹き出しの白箱を除去)→ `12`(孤立した白点)→ `13`(吹き出しの紺枠を検出して消去)→ `14`(手動の矩形を消し、独自パレットで描き直す)→ `15`(小さな点を周囲の色に)
5. 建物の輪郭: `20_geometry.py`(オレンジ領域の輪郭を取り、坂の矢印など 12 個を除外。複数棟がつながった塊は erode で分割。樹木 1,158 本は演出)
6. `21_export_rgba_and_poi.py` で透過つき ground.png と、敷地の輪郭・門・バス停の座標を出力
スケール: 150m の目盛りが 110dpi で約 258px → 0.581 m/px(300dpi では 0.2131 m/px)。
注意: 輪郭は公式図からの作図で、高さは公式図のエレベーター表記からの目安。ν棟は番号だけの表示のため、周辺ハウス群として表現した。
